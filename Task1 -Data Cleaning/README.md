# Task 01 - Data Cleaning and Visualization

## 📌 Objective

The objective of this project is to clean a real-world dataset, handle missing values, perform exploratory data analysis (EDA), and create meaningful visualizations.

---

## 📂 Dataset

Dataset Used:
- Titanic Dataset

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📊 Project Workflow

1. Import Libraries
2. Load Dataset
3. Explore Dataset
4. Handle Missing Values
5. Remove Unnecessary Columns
6. Check Duplicate Records
7. Save Cleaned Dataset
8. Create Visualizations

---

## 📈 Visualizations

- Survival Count
- Age Distribution
- Gender Distribution
- Passenger Class Distribution
- Survival by Gender
- Survival by Passenger Class
- Fare Box Plot
- Correlation Heatmap
